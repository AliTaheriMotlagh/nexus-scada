🚀 Getting Started

Nexus SCADA is an industrial monitoring and control system for plants, facilities, and smart homes. It displays real-time data, alerts you to problems, and lets you operate equipment.

What You'll Do

  • Monitor equipment status and sensor readings
  • Operate valves, pumps, switches and other devices
  • View Alarms and respond to issues
  • Analyze Trends using historical data
  • Design Pages (engineers only) to display information

🔐 Accessing the System

🖥️ Main Interface Overview

Navigation

The left sidebar contains the main menu:

  • Search bar – Find tags, displays, and information
  • Theme toggle – Switch between dark and light modes
  • User menu – See your role, sign out

📺 Viewing & Operating Displays

Navigating to a Display

Step 1: Click Runtime in the left sidebar.
Step 2: In the displays panel, expand folders and select a display page (e.g., Plant/Overview).
Step 3: The display appears in the center. You'll see:
  • Visual elements – Tanks, pumps, gauges, values
  • Real-time data – Values update every 100ms
  • Color indicators – Green = OK, yellow/orange = warning, red = alarm
  • Interactive controls – Buttons, switches, sliders (if you have operator role)

Understanding Display Elements

  • Gauge – Shows a numeric value on a scale
  • Value Display – Shows a number or text
  • Tank/Cylinder – Shows a filled level visually
  • LED Indicator – Red/green light showing on/off status
  • Pump/Motor Icon – Shows running (animated) or stopped
  • Button – Click to execute an action
  • Switch/Slider – Drag to change a value
💡 Tip: Hover over any element to see its name and current value.

🚨 Monitoring Alarms

Alarm Bar (Top Right)

The alarm bar shows a summary of active alarms:

Step 1: Look at the top-right corner for the alarm badge showing the count of active alarms.
Step 2: Click on the alarm badge to open the alarm bar and see:
  • Alarm count and severity (critical, high, medium, low)
  • Alarm horn status (muted or active)
  • Option to silence the alarm sound

Viewing Alarm Details

Step 1: Click Alarms in the left sidebar to open the Alarm Viewer.
Step 2: You'll see tabs for:
  • Active – Alarms that are currently happening
  • Shelved – Temporarily suppressed alarms
  • History – Past events
Step 3: For each alarm, you can see:
  • Message – What the problem is (e.g., "Tank level too high")
  • Severity – Critical, High, Medium, or Low
  • Time – When it started
  • Status – Active or acknowledged

Acknowledging an Alarm

Step 1: In the Alarm Viewer, click on an active alarm to select it.
Step 2: Click button.
Step 3: Optionally add a comment (e.g., "Pump repair in progress") and click .
Step 4: The alarm moves to the "Acknowledged" state but remains visible until the condition clears.
⚠️ Important: Acknowledging an alarm does NOT fix the problem. Take corrective action (operate equipment, check the process) to resolve the underlying issue.

📈 Viewing Trends & Historical Data

Opening the Trends Page

Step 1: Click Trends in the left sidebar.
Step 2: The trend viewer opens with:
  • Empty graph ready for data
  • Time range selector (e.g., last 1 hour, 24 hours, 7 days)
  • Tag selector to add data to the graph

Adding Data to a Trend

Step 1: Click the Tag Picker button to select which tag to graph.
Step 2: A tree of available tags appears. Expand folders and select a tag (e.g., Plant/Area1/Tank1/Level).
Step 3: The trend line appears on the graph showing historical values.
Step 4: Add up to 10 more pens (different tags) by repeating steps 1-3.

Interacting with Trends

  • Drag to zoom – Click and drag on the graph to zoom into a time range
  • Hover for values – Move your cursor over the line to see exact values and timestamps
  • Change time range – Use the time selector to view last hour, day, week, month, or custom range
  • Export to CSV – Click to download data
💡 Tip: Use trends to identify patterns, find when alarms started, and analyze process performance.

🎮 Operating Controls

Button

Buttons perform actions when clicked:

  • Simple button – Writes a value or triggers an action
  • Toggle button – Switches a value on/off with each click
  • Pulse button – Briefly turns something on then off (e.g., start/stop)
  • Confirmation button – Asks "Are you sure?" before executing
Step 1: Click the button on the display.
Step 2: If confirmation is required, a dialog appears. Click to proceed.

Switch / Toggle

Switches turn things on or off:

Step 1: Click or drag the switch to the ON or OFF position.
Step 2: The system sends the command and the switch updates to reflect the new state.

Slider

Sliders set numeric values (e.g., setpoint, speed):

Step 1: Click and drag the slider handle to the desired position.
Step 2: Release to send the command.
Step 3: The value display updates to show the new setpoint.
💡 Tip: For precise input, click the numeric value field and type the number directly instead of dragging.

Numeric Input / Text Input

Enter values directly by clicking the input field:

Step 1: Click on the input field.
Step 2: Clear the current value and type the new number or text.
Step 3: Press Enter to send the value, or press Esc to cancel.

Dropdown / Selector

Choose from predefined options:

Step 1: Click on the dropdown.
Step 2: Select an option from the list (e.g., "Mode: Auto", "Mode: Manual").
Step 3: The system sends the command.
⚠️ Safety Note: Be careful when operating equipment. Verify that the action is correct before pressing a button or moving a slider. Some operations may have consequences for the process.

✏️ Creating & Editing Displays (Engineers)

This section is for engineers who design the visual interface.

Accessing the Designer

Step 1: Click Designer in the left sidebar.
Step 2: You'll see:
  • Displays tree (left) – List of all pages
  • Canvas (center) – Your design area
  • Element palette (left panel) – Available symbols and controls
  • Layers panel (right) – All elements on this page
  • Property panel (right) – Customize selected element

Creating a New Display

Step 1: In the Displays tree, click the + New button.
Step 2: Enter a name for your page (e.g., Plant/Tank Status).
Step 3: The new blank page opens in the canvas.

Adding Elements to the Canvas

Step 1: In the Element Palette (left), find and click an element type (e.g., "Tank", "Pump", "Gauge").
Step 2: Move your cursor to the canvas and click to place the element.
Step 3: The element appears on the canvas and is selected. You can see its properties on the right.
Step 4: Resize: Drag the corner handles to make it larger or smaller.
Step 5: Move: Drag the element to reposition it.

Binding Elements to Tags

Connect visual elements to real process data:

Step 1: Select an element (e.g., a gauge or tank).
Step 2: In the Property Panel (right), find the Tag or Value field.
Step 3: Click the tag picker icon and select a tag (e.g., Plant/Area1/Tank1/Level).
Step 4: The element now shows live data from that tag. The gauge needle moves, the tank fills, or the value updates in real-time.

Adding Interactive Controls

Step 1: Add a button or switch from the palette.
Step 2: Select it and find the Write Tag field in properties.
Step 3: Select the tag to write to (e.g., Plant/Area1/Pump/Command).
Step 4: Set the Value to write when clicked (e.g., true for ON, false for OFF).
Step 5: Toggle to Preview Mode to test that the control works.

Design Tips

  • Use meaningful names – Label elements so operators understand what they control
  • Group related items – Group pump, valve, and sensor readings for the same tank
  • Choose colors carefully – Red for active/alarms, green for ok, gray for off
  • Add text labels – Use text elements to explain units (L, m³/h, °C)
  • Organize by section – Create separate pages for different areas (Area1, Area2, etc.)

Saving Your Design

Step 1: Click in the toolbar (or press Ctrl + S).
Step 2: The design is saved. You'll see a notification confirming success.
💡 Tip: Use undo (Ctrl + Z) and redo (Ctrl + Y) to fix mistakes.

💡 Tips & Troubleshooting

General Tips

  • Keyboard shortcuts: Ctrl + F to search for tags or displays
  • Responsive design: The system works on phones and tablets – zoom and scroll as needed
  • Dark mode: Click the theme toggle in the top bar to switch between light and dark
  • Real-time updates: Data updates every 100ms for subscribed tags – no need to refresh
  • Auto-save: Designs and configuration changes are auto-saved frequently

Common Issues

❌ "Device Offline" or "Connection Error"

  • Check the server: Make sure the Nexus SCADA server is running
  • Check the network: Verify your computer can reach the server's IP/URL
  • Refresh the page: Press Ctrl + F5 to reload
  • Check the device: The actual equipment (PLC, sensor, etc.) may be offline

❌ "Permission Denied" When Operating a Control

  • Check your role: Your user account may not have permission to write to this tag
  • Contact admin: Ask your administrator to upgrade your role to "operator" or "engineer"

❌ Data Not Updating on Display

  • Check tag binding: Make sure the element is bound to the correct tag path
  • Check device driver: The data source (modbus, MQTT, etc.) may be disconnected
  • View diagnostics: Go to Config → Devices to see connection status

❌ Alarms Not Triggering

  • Check alarm configuration: Alarms are defined in Config → Tags for each tag
  • Verify thresholds: The current value may not have exceeded the alarm limit
  • Check notification routing: Ensure email/SMS settings are configured if you expect external notifications

Performance

  • Many tags? – Subscribe only to the tags you need to reduce bandwidth
  • Slow trends? – Reduce the number of pens and use a shorter time range
  • Large displays? – Break them into smaller, focused pages

Safety Best Practices

  • 🔒 Secure your account: Use a strong password and keep it confidential
  • 📋 Document actions: When acknowledging alarms, add comments explaining what you did
  • ⚠️ Test carefully: Before deploying to production, test all controls in a safe environment
  • 👥 Follow procedures: Your facility should have standard operating procedures (SOPs) for critical operations
  • 🚨 Respond to alarms: Don't ignore alarms – investigate and fix the underlying problem

❓ Need Help?

If you encounter issues:

  • 📧 Contact your system administrator
  • 📚 Check the system's built-in help (click the ? icon if available)
  • 💻 Visit the documentation or wiki for your installation
  • 🐛 Report bugs with details: what you did, what happened, what you expected
